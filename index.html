Grid of shares

What the numbers mean

Data table

Each column is a set of data (for example a year). A sector's share is its part of the whole grid; type a share to resize it.

Paste data

One sector per line: its name, then one value per column, separated by tabs (as copied from a spreadsheet), semicolons or commas. A first line of column names is recognised. This replaces the current sectors; text blocks are kept.

Playback

Preview animation

Makes up random changes so you can preview how sectors move. Your data is not changed, and stopping restores it.

Small values

Raises tiny sectors so they stay readable. Sizes are then no longer exactly proportional.
